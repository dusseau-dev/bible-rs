## Bundled Bible translations — all public domain

Each translation is converted from the eBible.org USFM edition by `cargo run -p xtask -- build-data`.
The download URL and SHA-256 of every source archive are pinned in `xtask/src/main.rs` and recorded
in each translation's metadata (shown in Settings → Translations). Footnotes, cross-references,
Strong's numbers and introductions are dropped; the verse text itself is unchanged.

### Considered and not bundled

* **Bible in Basic English** — eBible.org lists it as public domain, but its status outside the
  United States is disputed (Cambridge University Press published the 1965 edition), so it is
  left out.
* **Translations with Apocrypha/Deuterocanon or non-KJV versification** (Douay–Rheims, Brenton
  Septuagint, …) — public domain, but they don't fit the 66-book KJV verse grid used for parallel
  and compare views. Users can import them; deuterocanonical books are skipped.
* **NLT, NASB, LSB, ESV, NIV, NKJV and any other copyrighted translation** — never bundled: no
  text, no derived index, no test fixtures. They can be imported from a file the user owns or
  fetched with the user's own API key (see the README).

## Test fixtures

Every importer and online-provider test uses public-domain wording (mostly KJV) in the *format*
of the source being tested (OSIS, Zefania, SWORD, ESV API text, API.Bible JSON). No copyrighted
Bible text appears anywhere in this repository.

## Web passage study data

The web reader's `Go deeper` panel uses two separately licensed data collections. The compact
JSON shards in `site/src/lib/server/study/data/` are generated by
`site/scripts/build-study-data.py` from pinned upstream revisions. The script removes HTML
formatting, indexes passage references, and truncates note text; these are modifications to the
original data. The generated shards retain their upstream licenses, not the MIT code license.

| Data | Credit and source | License |
|---|---|---|
| Aquifer Open Study Notes | © 2026 Mission Mutual, adapted from Tyndale Open Study Notes © 2023 Tyndale House Publishers; [source revision](https://github.com/BibleAquifer/AquiferOpenStudyNotes/tree/35183d839b73958deca66fe4060d4dc7d4dc23de) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| STEPBible tagged Hebrew and Greek data | Tyndale House Cambridge / STEPBible; [source revision](https://github.com/STEPBible/STEPBible-Data/tree/5de0a47f35f0fc13dfe1430d104e5db8a4285f9c) | [CC BY 4.0](CC-BY-4.0.txt) |

The panel links each displayed excerpt to its source and shows its license. Matthew Henry's
historic commentary is linked from CCEL; its original text is public domain, and the panel's
brief descriptions of his views are newly written. External search results are linked, not
bundled. YouTube cards contain links and public metadata only; no video or transcript is stored.
The Testimonials tab shows outbound links and public metadata from
[Christian Forums at Crosswalk](https://forums.crosswalk.com/), including one reviewed Genesis 3
link. Forum post bodies are neither bundled nor sent to the AI summary service. The forum's
[terms](https://forums.crosswalk.com/tos) do not state a third-party republication license.
The Academic tab includes outbound metadata links to open-access works indexed by
[OpenAlex](https://openalex.org/), plus one reviewed Genesis 3 article from Andrews University.
Paper bodies are not bundled or sent to the AI summary service. The History tab has brief,
newly written descriptions linking to the [Metropolitan Museum of Art](https://www.metmuseum.org/)
and [Israel Museum](https://www.imj.org.il/) records; museum images are not bundled. YouTube
search results use public title, channel, and duration metadata only.
